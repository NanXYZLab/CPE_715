# Request Access to the KU Community Cluster

Please request access using the KU CRC form:

<https://deptsec.ku.edu/~crc/forms/form/2>

When filling out the form, choose:

- **Cluster:** KU Community Cluster
- **Owner Group:** Nan Class

After you submit the request, the instructor will receive an authorization email to approve it. You should receive a welcome email after your access has been completed.

## Before Class

- Confirm that you received the welcome email.
- Follow any account-activation instructions in that email.
- Bring a laptop to class if possible.
- If you cannot bring a laptop, you may work with a partner during the guided exercise.

## Access Problems

If your request is still pending, tell the instructor. Do not request access to a laboratory research group or use another person's account.
