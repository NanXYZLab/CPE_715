# HPC Resources for CPE 715

These notes introduce the **KU Community Cluster** and connect directly to the
course water-simulation exercise.

The materials do not provide access to private research allocations,
laboratory directories, software installations, or research data.

## Course Workflow

1. [Request course access](01_Getting_Started/Request_Access.md)
2. [Log in and create a course workspace](01_Getting_Started/First_Login.md)
3. Review the [Linux command reference](02_Common_Commands/Linux_Basics.md)
4. Learn how to [find software modules](02_Common_Commands/Software_Modules.md)
5. Learn how to [submit and monitor Slurm jobs](02_Common_Commands/Slurm_Jobs.md)
6. Complete the [GROMACS water exercise](../Gromacs_water/README.md)

## Important Expectations

- Use only the course allocation and directories authorized for **Nan Class**.
- Never share passwords, authentication codes, private keys, or restricted data.
- Use the login node only for lightweight file management and job submission.
- Run simulations through Slurm on compute nodes.
- Cluster hostnames, modules, accounts, and partitions can change. Follow the
  instructor's current course announcement and the
  [KU CRC documentation](https://docs.crc.ku.edu/).
